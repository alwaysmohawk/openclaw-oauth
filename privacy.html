Privacy Policy

Effective October 11, 2026

Kiki is a personal AI assistant used by a single person (the "user"). This policy explains what Google user data Kiki accesses and how it is used.

Data Kiki accesses

When the user signs in with Google and grants permission, Kiki can access the Gmail data covered by the permissions she approved on Google's consent screen. This may include messages, metadata such as senders, subjects and dates, and labels. Kiki also receives her basic Google profile information (name and email address) to identify the connected account.

How the data is used

  • The data is used only to carry out tasks the user asks for, such as finding, summarizing, drafting, sending or organizing her own email.
  • To fulfill a request, the relevant email content is processed by an AI model (Anthropic's Claude) under the user's own Claude account.
  • The data is never used for advertising, sold, or used to build profiles. Kiki does not use it to train AI models.

Storage and security

Kiki runs on a private, access-controlled server. Google access tokens and any email content kept in the assistant's conversation history are stored only on that server. No one other than the user and the server's administrator has access to them.

Sharing

Google user data is not shared with any third party, except as needed to fulfill the user's requests (the AI processing described above) or when required by law.

Google API Services User Data Policy

Kiki's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The user can revoke Kiki's access at any time at myaccount.google.com/permissions. To ask for any stored data to be deleted, contact the email below.
